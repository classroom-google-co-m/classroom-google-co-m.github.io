# donate-to-aids.org — demo website

A small, responsive static website about HIV/AIDS awareness and ways to help.

## Run it
Open `index.html` in a modern browser. No build tools or server are required.

## Included
- Initial consent gate requiring a cookie preference and acceptance of the draft terms placeholder.
- Essential-only and accept-cookies choices, saved in browser local storage.
- Terms placeholder modal that is clearly marked as unfinished and not legal advice.
- Responsive navigation, educational sections, ways to help, and trusted external resource links.
- Stock photos loaded from Unsplash over the internet.

## Before public launch
- Replace the draft Terms of Service with reviewed terms and add a proper privacy/cookie notice.
- Confirm image licensing and replace remote stock image URLs if desired.
- Add verified organization details and donation links. This demo does not collect donations, payment details, or personal information.
- Test accessibility, security, and legal requirements for your jurisdiction.

This is a front-end demo, not a medical provider or donation processor. The consent screen is a UI demonstration, not a substitute for legally compliant consent management.
